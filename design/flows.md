# Productjvity flows

## Personal commitment

```text
Discover or create
  → define goal and measurable success
  → review complete TermsPanel
  → accept immutable rules version
  → active commitment
  → add milestones and private evidence
  → submit for verification
  → successful or unsuccessful
  → settlement receipt
```

## Evidence and verification

```text
Select permitted file
  → client checks type and size
  → private upload
  → evidence receipt
  → self-attestation, reviewer decision, or connected-service check
  → immutable verification decision
```

## Dispute

```text
Settled outcome
  → member opens dispute with reason
  → under review
  → uphold, re-verify, or correcting settlement entry
  → member receives a new auditable receipt
```

## Institutional programme

```text
Institution creates programme and rules v1
  → participant reads and accepts v1
  → enrolment
  → proof and review
  → settlement
  → results report
```
