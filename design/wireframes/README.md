# Wireframe handoff

The interactive visual baseline is currently [`../../design.html`](../../design.html). Before production implementation, create low-fidelity wireframes for each route in `design/IA.md` and validate these five tasks:

1. Create a personal commitment.
2. Join an institutional programme.
3. Upload proof.
4. Find and understand the outcome receipt.
5. Find dashboard progress and the next deadline.

Each wireframe must display the full `TermsPanel` before the acceptance action.
